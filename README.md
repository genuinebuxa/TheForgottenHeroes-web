# theforgottenheroes.hu

The Forgotten Heroes játék bemutató weboldala (magyar: `/`, angol: `/en/`). Statikus HTML/CSS, GitHub Pages szolgálja ki a `main` ág gyökeréből; a `CNAME` fájl köti a domainhez.

Helyi előnézet: `powershell -ExecutionPolicy Bypass -File tools/serve-website.ps1` → http://localhost:8080
